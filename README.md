# 🔮 World of Warcraft 3.3.5a (12340) — Obsidian Decompilation Vault

База знаний для **Obsidian**, содержащая свыше **24 000+ атомарных карточек** функций из проекта декомпиляции клиента World of Warcraft 3.3.5a (`Wow.exe`, билд 12340).

Каждая функция представлена в виде отдельной Markdown-заметки с указанием **виртуального адреса (Offset)**, **имени**, **модуля**, **сигнатуры C++** и **YAML-метаданных** для быстрого поиска и фильтрации.

---

## 📌 Откуда эти данные и зачем они нужны?

* **Источник:** Данные сгенерированы на основе открытого исходного кода проекта [wowdecomp](https://github.com/SatyPardus/wowdecomp) (автор — **SatyPardus** и контрибьюторы).
* **Назначение:** Персональная база знаний для исследователей, реверс-инженеров, разработчиков C++ и создателей модификаций для WoW.
* **Главные плюсы:**
  * 🔍 **Мгновенный поиск по OFFSET:** Введите HEX-адрес из IDA Pro / Ghidra (например, `0x0076C340`) и сразу перейдите к описанию и коду функции.
  * 📂 **Структура по модулям:** Функция разложена по подсистемам (`Engine/Storm`, `Engine/Gx`, `WoW/Objects`, `WoW/Frame` и др.).
  * 📊 **Интеграция с Dataview:** Карточки снабжены YAML-шапкой (`frontmatter`), что позволяет выводить динамические таблицы и списки функций в Obsidian.

---

## 🚀 Как открыть базу в Obsidian

- Скачайте или склонируйте этот репозиторий:

```bash
git clone https://github.com/gitalexhubuser/Obsidian-Decompilation-Vault
```

- Откройте приложение Obsidian.
- Нажмите кнопку «Открыть папку как хранилище» (Open folder as vault).
- Выберите папку со склонированным репозиторием.
- При первом открытии подождите 1–2 минуты, пока Obsidian проиндексирует все файлы.

# 💡 Как пользоваться поиском и навигацией

- Глобальный поиск по адресу или имени
- Нажмите Ctrl + Shift + F (или Cmd + Shift + F на macOS).
- Для поиска по конкретному адресу введите: offset: "0x0076C340"
- Для поиска по имени функции: CGUnit_C или SFileOpenFile

# Фильтрация по тегам

`#wowdecomp` — все карточки базы
`#module/engine_storm` — функции файловой системы и памяти Storm
`#module/engine_gx` — функции графического движка (D3D9 / OpenGL)
`#module/wow_objects` — игровые объекты (CGUnit_C, CGPlayer_C и т.д.)
